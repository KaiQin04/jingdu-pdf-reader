靜讀 PDF 閱讀器（試用版）

在 ChatGPT 對話旁閱讀自己的 PDF，邊看原文邊討論。支援的 ChatGPT 環境預設會在開檔後自動分享擷取的文字。

怎麼用
1. 在已接入靜讀的 ChatGPT 中開啟「PDF 閱讀器」，開檔前先確認「開啟 PDF 時自動分享文字」。預設開啟；只想本機閱讀請先關閉。
2. 選一份裝置上的 PDF，等狀態顯示「ChatGPT 已接受文字」，再回到對話提問，不需要另外按傳送。
3. 若要分享單一頁面或選取的文字，或自動分享未完成，可在「ChatGPT」面板手動預覽並傳送。環境不支援時，可複製預覽自行貼入對話。

只有在設定開啟時開啟的文件才會自動分享；重新勾選不會補送本機模式開啟的文件。每次開檔只自動嘗試一次，不會自動重送。關閉設定可停止尚未完成的擷取，但無法撤回已開始傳送的訊息。新開閱讀器視窗時，設定會恢復開啟。

分享的是預覽中的文字、檔名與 PDF 頁碼，不包含原始 PDF、圖片、圖表或本機註記。沒有文字層的頁面無法以文字分享；較大的文件請分次分享目前頁或選取的文字。

搜尋、目錄、雙頁／雙窗比較和註記，可以幫你查找、對照原文。

註記不會自動保存
註記只留在目前視窗，也不會改動原 PDF。關閉前，請在匯出預覽複製 JSON 或 Markdown，或另存截圖預覽（依瀏覽器支援）。重新開啟同一份 PDF 後，可匯入 JSON 接續註記。

「交由 ChatGPT 下載」
在支援的宿主中，按下後會把預覽的註記或截圖交給宿主，內容可能含檔名或引文。送出前請先檢查。獨立網站不支援宿主下載。

目前限制
沒有 OCR，純影像掃描檔無法搜尋，有文字層的掃描檔可以。不能編輯原 PDF，不能從網址載入，也沒有雲端同步。檔案上限 500 MiB／5,000 頁，大檔較耗記憶體。

靜讀 PDF 閱讀器（試用版）

在 ChatGPT 對話旁閱讀自己的 PDF，邊看原文邊討論。把想問的段落連同頁碼貼進對話，就能請 ChatGPT 解釋、比較或整理。

怎麼用
1. 在已接入靜讀的 ChatGPT 中開啟「PDF 閱讀器」，選一份裝置上的 PDF。
2. 選取想討論的文字，在「工具 → 搜尋」按「建立頁碼引用」，再按「選取引用文字」。
3. 按 Ctrl+C（Mac 為 ⌘+C）複製，貼到 ChatGPT 對話。
4. 請 ChatGPT 解釋、比較或整理這段內容。

搜尋、目錄、雙頁／雙窗比較和註記，可以幫你查找、對照原文。

註記不會自動保存
註記只留在目前視窗，也不會改動原 PDF。關閉前，請在匯出預覽複製 JSON 或 Markdown，或另存截圖預覽（依瀏覽器支援）。重新開啟同一份 PDF 後，可匯入 JSON 接續註記。

「交由 ChatGPT 下載」
在支援的宿主中，按下後會把預覽的註記或截圖交給宿主，內容可能含檔名或引文。送出前請先檢查。獨立網站不支援宿主下載。

目前限制
沒有 OCR，純影像掃描檔無法搜尋，有文字層的掃描檔可以。不能編輯原 PDF，不能從網址載入，也沒有雲端同步。檔案上限 500 MiB／5,000 頁，大檔較耗記憶體。

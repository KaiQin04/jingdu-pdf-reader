靜讀 PDF 閱讀器（公開試用版）

在瀏覽器裡閱讀自己的 PDF，支援搜尋、目錄、雙頁比較、註記與引用。

原始 PDF 不會上傳
PDF 只在你的瀏覽器裡開啟和解析，不會透過本服務上傳或存到伺服器。本閱讀器沒有自己的帳號系統、不加入分析追蹤器，也不主動呼叫 AI；託管平台仍可能處理一般存取紀錄及安全 Cookie。

關掉就沒了，記得先存
註記不會自動保存。關閉前請在註記工具裡複製 JSON 或 Markdown；區域截圖可另存圖片，是否可另存依瀏覽器支援。

在 ChatGPT 等宿主內使用時
「交由 ChatGPT 下載」會把預覽中的註記或截圖送給支援下載的宿主，內容可能包含檔名、原文引文等，送出前請先檢查。宿主怎麼處理這些資料，依宿主自己的規則。獨立網站沒有這個功能。

目前做不到的事
沒有 OCR：純影像掃描檔無法搜尋，已有文字層的掃描檔仍可搜尋。不能修改原 PDF、不能載入網址上的檔案、沒有雲端同步。檔案上限 500 MiB／5,000 頁；這是拒收上限，不是效能保證，大檔可能很吃記憶體。

試用階段提醒
請先用不敏感的文件測試。託管平台 Cloudflare 仍可能記錄 IP 和存取時間，這份說明不是絕對的安全保證。
